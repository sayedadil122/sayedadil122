## 🧪 How I Think About AI Products

- Start with the user problem, not the model.
- Treat grounding, hallucination, latency, trust, and failure handling as product metrics.
- Prototype fast, but validate whether the AI is actually useful in the workflow.
- Build feedback loops so the product improves after launch.
